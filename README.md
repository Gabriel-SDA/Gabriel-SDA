### 🛠️ Como isso funciona?

1. Um **GitHub Action** automatizado roda a cada 12 horas.
2. O script lê meu histórico de commits públicos no GitHub.
3. Ele gera a animação do jogo da cobrinha jogando em cima dos quadradinhos de contribuição.
4. As animações são salvas em formato SVG na branch `output` deste repositório e exibidas aqui no README!
